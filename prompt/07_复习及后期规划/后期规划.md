## 二、课程定位：从「会搭智能体」到「能做 AI 应用工程师」

这一阶段的目标不是背模型名词，也不是只会拖拽工作流，而是完成一次能力升级：

**从「我会用 Coze / Dify 搭 Bot」→「我能用 Python、API、RAG、Agent 做出可上线、可面试、可交付的 AI 应用」。**

当前 AI 岗位市场有一个清晰趋势：**企业更需要能把大模型接入真实业务的人**，而不是只会推导公式的人。我们的培养重心是 **AI 应用开发为主、纯算法为辅**——先能干活、能讲项目、能入职，再按兴趣往算法方向深造。

## 三、需要建立的 4 个认知

### 1. 低代码平台是起点，不是终点

Coze、Dify 让你们快速验证了 RAG、Agent、工作流的价值。但企业落地时，往往还需要：

```
低代码原型验证 → Python API 开发 → 向量检索 → 业务数据库 → 部署运维 → 成本与安全控制
```

**平台搭过的能力，后面要用代码再实现一遍**——这样面试时才能讲清楚「平台里那个节点，底层是怎么工作的」。

### 2. 不要只追模型，要追「应用场景」

模型每天都在变，企业关心的是：你能不能做智能客服、知识库问答、资讯打标、合同分析、数据分析助手、自动化办公……

学习重点是一套通用能力：

- 输入怎么处理
- 知识怎么检索
- 模型怎么调用
- 工具怎么接入
- 结果怎么验证
- 系统怎么上线

### 3. 岗位导向：AI 应用开发 > 纯算法

结合当前招聘市场，你们应优先对齐的方向：

| 岗位方向 | 核心能力 | 匹配度 |
|---------|---------|--------|
| **AI 应用开发工程师** | Python + FastAPI + 大模型 API + RAG + Agent | ⭐⭐⭐⭐⭐ 主方向 |
| **RAG / 知识库开发工程师** | Embedding、向量库、文档切分、检索优化 | ⭐⭐⭐⭐⭐ 主方向 |
| **Agent / 智能体开发工程师** | 工具调用、工作流、多 Agent 协作 | ⭐⭐⭐⭐⭐ 主方向 |
| **Dify / Coze 应用开发** | 平台编排 + 私有化部署 + 企业集成 | ⭐⭐⭐⭐ 过渡方向 |
| **Prompt 工程师** | 提示词模板、结构化输出、业务场景设计 | ⭐⭐⭐⭐ 已具备基础 |
| **纯算法 / 模型训练工程师** | 数学、深度学习、微调、论文级优化 | ⭐⭐ 辅线，非当前主线 |

**结论**：把 80% 精力放在「能做出项目、能讲清楚链路」上；算法原理理解到能面试表达即可，不必急于成为研究员。

### 4. 项目比知识点更重要

AI 技术变化很快，但项目能力长期有效：需求分析、系统设计、接口开发、数据处理、错误排查、部署上线、项目表达——这些不会过时。

### 阶段三：Embedding 与 RAG 知识库（代码级）

**目标**：把 Coze / Dify 里搭过的 RAG，用 Python 完整实现一遍。

**核心内容**：

- Embedding 原理与文本向量化
- 文档切分策略（PDF / Word / Markdown）
- 向量数据库（FAISS、Chroma 基础）
- TopK 召回、Rerank、上下文拼接
- 引用来源、幻觉控制
- 检索质量评估（准确率 / 召回率概念）

**理解要点**：

- 大模型不知道企业内部资料
- RAG = 先检索再回答，减少幻觉（但不能完全消除）
- 效果取决于文档质量、切分策略、检索质量、Prompt 设计

**阶段项目：企业知识库问答系统**

- 文档上传 → 切分 → 向量化 → 入库
- 用户提问 → 检索 → 大模型回答 → 显示引用来源
- 支持历史对话、知识库重建

**简历写法参考**：基于 FastAPI + 向量数据库 + 大模型 API 实现 RAG 企业知识库，支持文档上传、语义检索、引用溯源与多轮对话。

## 十、学习要点（请记住）

### Python 仍然是根基

AI 再强，也要靠代码落地。前面 Python 进阶（面向对象、闭包装饰器、多进程多线程、网络编程、生成器协程、正则）不是白学——后面所有 AI 项目的接口、并发、数据处理都会用到。

### 平台经验要转化为代码理解

Coze 里做过的「知识库检索节点」「意图识别节点」「数据库查询节点」，后面用 Python 实现时，你要能一一对应：**平台上的一个方块 = 代码里的一个函数或模块**。

### AI 不是替你学习，而是放大学习能力

不能只复制 AI 代码，必须：**看得懂、跑得通、改得动、讲得清、能排错、能优化**。

### 先就业，再深造

对当前阶段来说，更现实的目标是：**先能做 AI 应用 → 再理解模型原理 → 最后根据兴趣深入算法**。不必一步成为算法专家。
