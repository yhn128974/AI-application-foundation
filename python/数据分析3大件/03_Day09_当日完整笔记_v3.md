## 二、Python 数据分析三剑客

### 1. [了解] 各自解决什么问题

|----|--------------|----------|------|----------------|

### 2. [理解] 依赖层次与互补（PPT 第 8～9 页）

```text
基础层 NumPy（ndarray、数值计算）
    ↓ 底层存储与运算
```

- **依赖**：Pandas、Matplotlib 都站在 NumPy 上；列的 `values` 往往是 `ndarray`。
- **互补**：不是「会 Pandas 就不用 NumPy」——`dtype`、`axis`、向量化问题常要回到数组层排查。

### 3. [理解] 标准工作流

```text
准备数据 → NumPy 计算/生成 → Pandas 表格处理 → Matplotlib 展示
```

**口诀**：NumPy 算得快，Pandas 表好处理，Matplotlib 图画得出来。

**场景题**：分析 AI 应用「每日用户提问次数」——计算用 NumPy，整理成表用 Pandas，画趋势用 Matplotlib。

### 4. [技能] 三库最短闭环（知道终点即可）

## 三、NumPy 核心操作

### 1. [掌握] 导入与规范

- **写法**：`import numpy as np`（行业惯例，面试/开源代码均如此）
- **技能点**：不要随便改别名，否则协作阅读成本高

### 2. [掌握] `ndarray` 是什么

- **定义**：同质、定长、多维数组；科学计算与后续 Pandas/sklearn 的底座。
- **对比 Python 列表**：列表可混类型、逐元素循环慢；`ndarray` 适合**批量数值计算**（快一个数量级以上常见）。

### 3. [掌握] 创建数组 — API 速查（代码见讲义）

| API | 作用 | 记忆/易错 |
|-----|------|-----------|
| `np.array([...])` | 列表 → 数组；嵌套列表 → 二维 | 外层一行、内层一列 |
| `np.zeros((行, 列))` | 全 0，初始化、占位 | shape 是**元组** `(2,3)` |
| `np.ones((行, 列))` | 全 1 | 同上 |
| `np.arange(起, 止, 步)` | 范围数组 | **左闭右开**，不含止点 |
| `np.linspace(起, 止, 个数)` | 等份切分 | **含终点**，要 n 个点 |
| `np.random.rand(m,n)` | [0,1) 均匀 | 无 `n` = normal |
| `np.random.randn(m,n)` | 标准正态 | **randn** 的 n = normal |

### 4. [掌握] 数组属性

| 属性 | 含义 |
|------|------|
| `ndim` | 维度数（1 维一条线，2 维一张表） |
| `shape` | 形状，如 `(3, 4)` = 3 行 4 列 |
| `size` | 元素总数 = shape 各维相乘 |
| `dtype` | 元素类型（影响内存与精度） |

**小算**：`shape (3, 4)` → `size = 12`。

### 5. [掌握] 形状改变

| 操作 | 作用 | 规则 |
|------|------|------|
| `reshape(行, 列)` | 改形状，**不改变数据** | reshape 前后 **size 必须相等** |
| `.T` | 转置（行列互换） | |
| `.flatten()` | 展平为一维 | |

**易错**：12 个元素可 `(3,4)`、`(2,6)`，不能 `(5,3)`。

### 6. [掌握] 基础运算（向量化）

- **含义**：同形状数组按**对应位置**一次算完，不要手写 for。
- `a + b`、`a * b`：逐元素加/乘  
- `a > 2`：比较 → **布尔数组**  
- **易错**：`*` 是逐元素乘，**不是**矩阵乘；矩阵乘用 `@`、`np.matmul()`、`np.dot()`。

### 7. [掌握] 统计运算与 `axis`（高频考点）

| 函数 | 无 axis | `axis=0` | `axis=1` |
|------|---------|----------|----------|
| `np.sum` 等 | 全体一个数 | **按列**聚合（每列一个结果） | **按行**聚合（每行一个结果） |

**口诀**：**axis 指向被「消掉」的轴** —— `axis=0` 沿行方向压扁 → 得到每列统计；`axis=1` 沿列方向压扁 → 得到每行统计。  
（与 Pandas `groupby`、后续机器学习里「沿哪维聚合」同一套逻辑。）

常用：`sum`、`mean`、`max`、`min`。

### 8. [理解] 广播机制（PPT 第 19 页）

- **为什么学**：不同形状数组有时能直接 `+`、`*`，不用手动扩维循环。
- **直觉**：小数组沿缺失维「复制」到大数组形状再运算。
- **课堂例子**：`(3,3) + (3,)` → 行向量广播到每一行；`(3,3) * (3,1)` → 列向量广播到每一列。
- **规则（知道即可）**：从**最后一维**对齐，维度相等或一方为 1 可广播。

## 四、Pandas 核心操作

### 1. [掌握] 导入

- `import pandas as pd`

### 2. [掌握] Series 与 DataFrame

| 结构 | 维数 | 特点 | 类比 |
|------|------|------|------|
| **Series** | 一维 | `values` + `index`（标签） | 一列带行名 |
| **DataFrame** | 二维 | 列名 + 多列，列可不同 `dtype` | Excel 表 |

**技能点**：`df.shape`、`df.columns`、`df.dtypes` 是读表后「先看结构」三件套。

### 3. [掌握] 读文件与窥探数据

| 方法/参数 | 作用 |
|-----------|------|
| `pd.read_csv(路径)` | 读 CSV/类表格文本 |
| `sep` | 分隔符（`,`、`-` 等，读错会整表乱） |
| `names=[...]` | 无表头时手动指定列名 |
| `head()` / `tail()` | 前/后几行，确认读对 |
| `describe()` | 数值列 count/mean/std/min/max |
| `info()` | 行数、每列非空数、dtype |

**排错顺序**：路径 → `sep` → 有无表头 → `names`。

### 4. [掌握] `loc` 与 `iloc`

| | `loc` | `iloc` |
|---|-------|--------|
| 依据 | **标签**（行 index、列名） | **整数位置**（0 起） |
| 记忆 | label | **i**nteger |

**技能点**：`df.loc[行标签, 列名]`、`df.iloc[行号, 列号]`；取整列常用 `df.loc[:, "name"]`、`df.iloc[:, 0]`。

### 5. [掌握] 条件筛选与排序

- **单条件**：`df[df["列"] > 值]`  
- **多条件**：`df[(条件1) & (条件2)]` —— 必须用 **`&`**，每个条件**加括号**；不能用 Python 的 `and`。  
- **排序**：`df.sort_values("列名", ascending=False)` 降序。

### 6. [掌握] 分组聚合 `groupby`

- **作用**：按某列分组，再对指定列做统计（类似 SQL `GROUP BY`）。
- **常用**：`count()`、`sum()`、`mean()`、`max()`、`min()`  
- **多指标**：`.agg(["max", "min", "mean"])`  
- **延伸（PPT）**：`pivot_table(index=..., values=..., aggfunc=...)` ≈ Excel **数据透视表**；与 `groupby` 相比更偏「二维汇总表」展示。

### 7. [掌握] 缺失值处理

| 方法 | 作用 | 使用注意 |
|------|------|----------|
| `isnull().sum()` | 每列缺多少 | 分析第一步 |
| `dropna()` | 删含缺失的行/列 | 不要无脑全删 |
| `fillna(值)` | 填充 | 如 `fillna(df.mean())` 用均值填数值列 |

## 五、Matplotlib 基础图表

### 1. [了解] 作用与图型选择

| 图型 | 适合看什么 |
|------|------------|
| **折线图** | 趋势、时序（销量、调用量随时间） |
| **柱状图** | 类别对比 |

### 2. [掌握] 折线图关键步骤（无长代码）

1. （可选）`matplotlib.use("TkAgg")`

3. 设中文字体、`axes.unicode_minus`  
4. `plt.plot(x, y, marker=..., label=...)`  
5. `title` / `xlabel` / `ylabel` / `grid` / `legend`  
6. **`plt.show()`** —— 没图先查是否调用  

**散点图**：`plt.scatter(x, y)` + 同上装饰；教学可用 `np.random.seed` 保证结果可复现。

## 六、重难点与易错点速查

| 易错 | 正确理解 |
|------|----------|
| 把 `ndarray` 当普通 list 循环算 | 用向量化 API |
| `reshape` 元素总数对不上 | 新 shape 乘积 = 原 `size` |
| `*` 当矩阵乘 | 逐元素用 `*`；矩阵用 `@` |
| `axis=0/1` 反了 | 记口诀：axis=0 → 每**列**一个结果 |
| `loc` / `iloc` 混用 | 标签 vs 位置 |
| 多条件用 `and` | 用 `&` 且条件加括号 |
| 图不显示 | `plt.show()`、后端 TkAgg |
| 中文方框 | `font.sans-serif` 设黑体等 |
