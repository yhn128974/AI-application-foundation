### 二. 操作系统和 Linux 概述

#### 1. [了解]计算机组成

* **硬件资源**：看得见、摸得着的设备，比如 CPU、内存、硬盘、网卡、键盘。
* **软件资源**：看得见、摸不着的程序，比如操作系统、浏览器、PyCharm、数据库。
* **核心关系**：硬件提供能力，软件使用能力，操作系统负责管理和协调。

#### 2. [理解]操作系统的作用

* **概念**：操作系统是管理计算机硬件和软件资源的系统软件。
* **作用**：让应用软件能够方便地使用 CPU、内存、硬盘、网络等资源。
* **类比**：操作系统像一位管家，硬件是房子里的资源，应用软件要用资源时，需要通过管家安排。

#### 3. [了解]常见操作系统

* **Windows**：适合日常办公、游戏、普通电脑使用。
* **macOS**：适合设计、开发、苹果生态。
* **Linux**：适合服务器、云平台、嵌入式系统。

### 三. Linux 发行版和课堂环境选择

#### 1. [了解]Linux 发行版

* **Linux 内核**：操作系统的核心。
* **Linux 发行版**：不同团队基于 Linux 内核，加上工具、软件包、配置后形成的完整系统。
* **常见发行版**：Ubuntu、CentOS、RedHat、Debian、Deepin。

#### 2. [理解]Ubuntu 和 CentOS 的区别

* **Ubuntu**：使用 `apt` 管理软件包，新手资料多，AI 和开发工具教程很多默认使用 Ubuntu。
* **CentOS**：传统服务器教程中常见，和 RedHat 生态关系密切，PPT 中原本以 CentOS 为虚拟机示例。
* **课堂选择**：本节课使用腾讯云 Ubuntu 云服务器，减少 VMware 安装等待，也更贴近真实服务器场景。

#### 3. [互动提问]

* **问题**：Ubuntu 和 CentOS 是不是完全不同的两套命令？
* **答案**：不是。它们都是 Linux 发行版，基础命令大量通用，主要差异体现在包管理、默认配置和生态习惯上。

### 四. 获取 Linux 环境：虚拟机和云服务器

#### 1. [了解]虚拟机

* **概念**：通过虚拟化软件，在本机电脑里模拟出一台新电脑，并安装操作系统。
* **PPT 原方案**：VMware + CentOS。
* **优点**：本地可控，不依赖云平台。
* **不足**：安装时间较长，不同电脑可能遇到虚拟化、网卡、镜像安装等问题。

#### 2. [了解]云服务器

* **概念**：云平台提供的一台远程 Linux 服务器。
* **课堂方案**：腾讯云 AI 助手辅助创建 Ubuntu 云服务器。
* **优点**：创建快，更接近真实工作中的服务器使用方式。
* **注意**：云服务器可能产生费用，配置、带宽和费用以云平台页面为准；不用时及时关机或释放。

#### 3. [掌握]SSH 连接需要的信息

* **公网 IP**：服务器地址。
* **端口**：SSH 默认端口是 22。
* **用户名**：Ubuntu 常见为 `ubuntu`，实际以控制台为准。
* **认证方式**：密码或密钥。

### 五. Linux 目录结构和命令格式

#### 1. [掌握]Linux 单根目录结构

* **Windows**：有 C 盘、D 盘。
* **Linux**：只有一个根目录 `/`，所有文件都在 `/` 下面。

```text
Windows 示例：D:\data\work\hello.txt
Linux 示例：/home/ubuntu/hello.txt
```

#### 2. [掌握]常见目录

* `/`：根目录。
* `/home`：普通用户家目录所在位置。
* `/root`：root 用户家目录。
* `/etc`：配置文件。
* `/usr`：用户程序和资源。
* `/tmp`：临时文件。
* `/var`：日志、缓存等经常变化的文件。

#### 3. [掌握]命令基础格式

```text
command [-options] [parameter]
```

* **command**：命令本身。
* **options**：选项，用来控制命令细节。
* **parameter**：参数，通常表示操作目标。

### 六. 四大基础命令

#### 1. [掌握]pwd、ls、cd、clear

> ```bash
> # pwd：查看当前所在目录。
> pwd
> 
> # ls：查看当前目录下有哪些文件和目录。
> ls
> 
> # cd：切换目录。
> cd /home
> 
> # clear：清屏。
> clear
> ```

#### 2. [掌握]常用路径动作

> ```bash
> # 回到当前用户的家目录。
> cd ~
> 
> # 回到上一级目录。
> cd ..
> 
> # 查看 /home 目录下的内容。
> ls /home
> ```

#### 3. [避坑指南]

* 操作文件前先 `pwd`，确认自己在哪里。
* 不确定目录里有什么，先 `ls`。
* Linux 路径使用 `/`，不是 Windows 的 `\`。

### 七. 目录和文件基础操作

#### 1. [掌握]mkdir 创建目录

> ```bash
> # 回到家目录，避免在系统目录里乱操作。
> cd ~
> 
> # 创建课堂练习目录。
> mkdir linux_demo
> 
> # 进入课堂练习目录。
> cd linux_demo
> 
> # 创建多个同级目录。
> mkdir notes logs scripts
> 
> # 创建嵌套目录。
> # -p 表示父目录不存在时自动创建。
> mkdir -p project/data/raw
> ```

#### 2. [掌握]touch 创建文件

> ```bash
> # 创建一个空文件。
> touch notes/day10.txt
> 
> # 一次创建多个文件。
> touch logs/app.log logs/error.log
> ```

#### 3. [掌握]cat、more、head、tail 查看文件

> ```bash
> # cat 适合查看小文件。
> cat notes/day10.txt
> 
> # more 适合分页查看较大文件。
> more notes/day10.txt
> 
> # head 默认查看文件前 10 行。
> head notes/day10.txt
> 
> # tail 默认查看文件后 10 行。
> tail notes/day10.txt
> ```

### 八. 写入、复制、移动、删除和打包

#### 1. [掌握]echo 和重定向

> ```bash
> # > 表示覆盖写入。
> echo "Day10 Linux command practice" > notes/day10.txt
> 
> # >> 表示追加写入。
> echo "Linux is important for AI deployment." >> notes/day10.txt
> 
> # 查看写入结果。
> cat notes/day10.txt
> ```

#### 2. [掌握]cp、mv、rm

> ```bash
> # 复制文件。
> cp notes/day10.txt logs/day10_copy.txt
> 
> # 移动文件，也可以用于改名。
> mv logs/day10_copy.txt logs/day10_moved.txt
> 
> # 删除文件。
> rm logs/day10_moved.txt
> 
> # 复制目录需要 -r。
> cp -r notes notes_backup
> 
> # 删除目录需要 -r。
> rm -r notes_backup
> ```

#### 3. [掌握]tar 打包压缩

> ```bash
> # 普通打包，不压缩。
> tar -cvf linux_demo.tar notes logs scripts
> 
> # gzip 压缩打包。
> tar -zcvf linux_demo.tar.gz notes logs scripts
> 
> # 创建解压目录。
> mkdir unpack_demo
> 
> # 解压到指定目录。
> tar -zxvf linux_demo.tar.gz -C unpack_demo
> ```

#### 4. [避坑指南]

* `>` 会覆盖原内容，`>>` 是追加内容。
* `rm` 删除通常没有回收站。
* 不要对不确定路径随便使用 `rm -rf`。
* 删除前先 `pwd` 和 `ls` 确认。

### 九. vim 文本编辑器

#### 1. [掌握]vim 三种模式

* **命令模式**：刚进入 vim 时默认模式，按键会被当成命令。
* **输入模式**：按 `i` 进入，可以输入文字。
* **底线命令模式**：按 `:` 进入，可以保存和退出。

#### 2. [掌握]基础编辑流程

> ```bash
> # 打开或创建文件。
> vim notes/vim_demo.txt
> ```

进入 vim 后：

```text
1. 按 i，进入输入模式
2. 输入 hello linux
3. 按 Esc，回到命令模式
4. 输入 :wq，保存并退出
```

#### 3. [掌握]常用底线命令

* `:w`：保存。
* `:q`：退出。
* `:wq`：保存并退出。
* `:q!`：不保存强制退出。

#### 4. [避坑指南]

* 如果不能输入内容，说明还在命令模式，先按 `i`。
* 如果不知道自己在哪个模式，先按 `Esc` 回到命令模式。
